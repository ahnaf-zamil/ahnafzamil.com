# .ai/ — Persistent Project Context

This directory documents architectural decisions, conventions, and invariants
for AI coding sessions. It avoids duplicating what source code trivially reveals.

**Files:**

| File | Purpose |
|------|---------|
| `project.md` | Stack, structure, domain, features |
| `architecture.md` | Component hierarchy, data flow, boundaries |
| `conventions.md` | Code style, naming, patterns |
| `decisions/` | ADR-style records of non-obvious architectural choices |

**Source of truth:** actual source code in `src/`.
